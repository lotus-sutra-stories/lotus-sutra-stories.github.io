## 文字校勘（兩本異文對照）

| 《持驗記》（詳） | 《顯應錄》（略） |
|---|---|
| 始涉半載，即于定中見佛光照地皆作金色 | 一日縈疾注念次，見佛白毫光 |
| 居十五年，正念佛時見阿彌陀佛玉毫光照 | 又見彌陀身紫金山，毫光散彩 |
| 蓮華青白，其水湛湛 | 身入七寶池，飲八功德水 |
| 義熙六年卒，異香七日而息 | 未記卒年 |
| 遠公為撰紀德碑 | 請眾僧共轉此經數百徧以助其行 |

- 《顯應錄》獨有：「程之請佛摩頂，覆我以衣，佛即為摩頂，引衣覆之」；「劉得如此，全是法華經力」句。
- 《持驗記》獨有：卍字胸相之人指水令飲、發願文全篇、義熙六年卒年。
- 兩本發願結構同為「釋迦→彌陀→法華經」三段供養，此為本條核心。
