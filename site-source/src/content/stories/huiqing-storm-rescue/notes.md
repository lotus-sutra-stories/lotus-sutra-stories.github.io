# 考證與異文 — 慧慶

## 版本與出處

- 見證一：《法華經顯應錄》卷一「高僧」門「廬山慶法師」條（X78n1540_p0031c05），夾注「法苑珠林」。
- 見證二：《法華經持驗記》卷一宋朝「宋釋慧慶」條（X78n1541_p0067a23）。
- 底本：CBETA X78 數位版，2026-10-23 核對。

## 文字校勘（兩本異文對照）

| 《顯應錄》 | 《持驗記》 |
|---|---|
| 誦法華、維摩等經 | 誦法華、思益等經 |
| 甞於小雷遇風，船將沈 | 渡江遇風，舟將覆 |
| 覺有扶挽之者，倐忽到岸 | 覺舟在波濤中，迎飈截流，如有人，如有人牽之，倐忽抵岸 |

- 「小雷」：《顯應錄》指小雷山江面（彭蠡附近），譯文保留原詞。
- 「倐忽」為「倏忽」之異體，依底本保留。

## 分類依據

- 主題：現世安樂；次類：免難與救護、吉祥瑞相（彈指聲）。
- 往生欄位：全條無往生語，not-stated／unspecified／uncertain。
