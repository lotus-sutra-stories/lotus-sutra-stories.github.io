# 考證與異文 — 曇翼

## 版本與出處

- 見證一：《法華經顯應錄》卷一「高僧」門「天衣飛雲大師」條（X78n1540_p0033b01）。原書夾注二則：「即今天衣寺是」「師事迹，僧傳、珠林皆紀之。天衣又有本傳、實錄，所有異同處，謹詳而錄之」。
- 見證二：《法華經持驗記》卷一晉朝「晉釋曇翼」條（X78n1541_p0066a18），開頭節載聽經雉因緣。
- 底本：CBETA X78 數位版，2026-10-23 核對。

## 文字校勘（兩本異文對照）

| 《顯應錄》（詳） | 《持驗記》（略） |
|---|---|
| 入山采薇，路逢猛虎，奔遁至此 | 入山采薇，日夕矣，豺狼縱橫 |
| 以巾布裹錫杖頭，遙以案摩 | 以布裹錫杖，遙為按之 |
| 晉安帝義熙十三年（有年號） | 義熙十三年（同） |
| 吳越武肅王諡飛雲大師 | 師既化，漆其身留山中 |

- 《持驗記》本明言「敕建法華寺，即今天衣寺也」；《顯應錄》以夾注出之。
- 「案摩」即「按摩」之古寫；「顗」＝孟顗，二本同（《顯應錄》作「孟公顗」）。
- 「雙㵎」之「㵎」為「澗」之異體，依底本保留。

## 分類依據

- 主題：現世安樂；次類：護經與菩薩感應（普賢現身）、吉祥瑞相（雨華地動）。
- rebirthClaim=interpreted／reportedDestination=**other**：普賢明言「不久當歸我眾」——預記歸入普賢眷屬，非西方淨土。aspirationForSukhavati=uncertain（全條無淨土願行語）。
