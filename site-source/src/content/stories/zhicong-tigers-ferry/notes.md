# 考證與異文 — 智聰

## 版本與出處

- 見證一：《法華經顯應錄》卷一「高僧」門「揚州聰法師」條（X78n1540_p0039b07）。
- 見證二：《法華經持驗記》卷一唐朝「唐攝山棲霞寺釋智聰」條（X78n1541_p0075b14）。
- 底本：CBETA X78 數位版，2026-10-23 核對。

## 文字校勘（兩本異文對照）

| 《顯應錄》（詳） | 《持驗記》（略） |
|---|---|
| 聰曰：吾已十日不食，命在呼吸間，卿可食之 | （無此節） |
| 值大隋國崩 | 值隋亡 |
| 艇及老人忽不見 | 艇及老人忽不見 |
| （未言止棲霞） | 師携四虎止棲霞寺西，貞觀中年九十九端坐逝，虎哀吼而去 |

- 《顯應錄》末句《持驗記》較詳：貞觀中九十九歲卒，虎哀吼而去——本站譯文兩邊互補已註明來源。
- 「將無渡耶」：「將無」為六朝口語「莫非／是不是」之意。

## 分類依據

- 主題：現世安樂；次類：免難與救護、安心精進。
- 往生欄位：全條無往生語，not-stated／unspecified／uncertain。
