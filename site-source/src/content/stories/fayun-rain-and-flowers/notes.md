# 考證與異文 — 法雲

## 版本與出處

- 見證一：《法華經顯應錄》卷一「高僧」門「金陵雲法師」條（X78n1540_p0034a20），夾注「續高僧傳」。
- 見證二：《法華經持驗記》卷一梁朝「梁釋法雲」條（X78n1541_p0069a24）。
- 底本：CBETA X78 數位版，2026-10-23 核對。

## 文字校勘（兩本異文對照）

| 《顯應錄》（詳） | 《持驗記》（略） |
|---|---|
| 曾往幽巖，獨講是經，列石為徒 | （無此節） |
| 天華狀如飛雪……升空不墜，講訖乃去 | 天華滿空，下如飛雪 |
| 武帝問誌計得雨 | （武帝問誌一節同，較略） |
| 燈明佛時已講此經 | 燈明佛時已講此經（同） |

- 《持驗記》云「年三十，於妙音寺開講」，《顯應錄》未書寺名；又稱誌公「每來雲所，輒停信宿，稱為大林法師」——此等細節《顯應錄》皆略。
- 「其澤普洽」：《法華經・藥草喻品》句（「如彼雲雨……其澤普洽」），講經至此而雨至，正是品題與時雨的呼應。
- 「燈明佛」：《法華經・序品》日月燈明佛說《法華經》之典。

## 分類依據

- 主題：現世安樂；次類：吉祥瑞相（天華、致雨）、護經與菩薩感應（誌公之印可）。
- 往生欄位：全條無往生語，not-stated／unspecified／uncertain。
