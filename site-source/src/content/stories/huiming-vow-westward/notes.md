# 考證與異文 — 慧命

## 版本與出處

- 見證一：《法華經顯應錄》卷一「高僧」門「後周命法師」條（X78n1540_p0030b07），夾注「續高僧傳」。
- 見證二：《法華經持驗記》卷一北周「北周釋慧命」條（X78n1541_p0071a08）。
- 底本：CBETA X78 數位版，2026-10-23 核對。

## 文字校勘（兩本異文對照）

| 《持驗記》（詳） | 《顯應錄》（略） |
|---|---|
| 年十五誦法華，兩旬有半，一部都徹 | 十五誦法華經，兩旬之間，終始通利 |
| 專行方等、普賢等懺法 | 專修法華懺法 |
| 跏趺西向念佛，咸睹佛來 | 面西加趺正坐，覩佛來迎 |
| 合掌而蛻，奇香異樂，聞薰非一 | 合掌而寂；合眾同夢天人下地，幢旛映日 |

- 《顯應錄》獨有：「又有聞奇樂異香，稱讚善哉之者」，並記「合眾同夢天人下地，幢旛映日」。
- 《持驗記》獨有：仙城山善光寺講演、戴逵貽書酬札、法音同學、松林立願等情節。
- **底本脫文**：《持驗記》本條至「奇瑞悉與師」句戛然而止，文句未完；其下即接「北周釋慧遠」條。此為底本（卍續藏影印）如此，CBETA 數位版如實收錄，本站照錄不補。

## 分類依據

- aspirationForSukhavati=true：「剋志西邁」（與法音共立西邁之誓）明確可考。
- reportedDestination=sukhavati：「跏趺西向念佛」「咸睹佛來」——方向與行法均指向西方；惟原書未指名阿彌陀佛，故據「西向念佛」歸入西方。
- rebirthClaim=interpreted：原書以「咸睹佛來、合掌而蛻、奇香異樂」收束，未以敘事口吻明言往生何處。
