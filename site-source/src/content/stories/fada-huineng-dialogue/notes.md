# 考證與異文 — 法達

## 版本與出處

- 唯一原典見證：《法華經持驗記》卷一唐朝「唐韶州南華寺釋法達」條（X78n1541_p0076b07）。
- 底本：CBETA X78 數位版，2026-10-23 核對。

## 文字校勘（與《壇經》對照）

- 本條與《六祖大師法寶壇經・機緣品》法達章文字大體同源而互有詳略：《壇經》有法達自陳「誦法華經已及三千部」、六祖告「此經……無數方便種種因緣譬喻言詞」一段及法達問「未審出世之因」等語，《持驗記》皆略去；《持驗記》「但依文念，豈知宗趣」句，《壇經》作「未審經中義理宗趣」。
- 「經誦三千部，曹溪一句亡」：《壇經》作「經誦三千部，曹溪一句亡」，同。
- 「心迷法華轉」四句偈：《壇經》作「心迷法華轉，心悟轉法華；誦經久不明，與義作讎家；無念念即正，有念念成邪；有無俱不計，長御白牛車」，《持驗記》全同。
- 兩源之先後：《壇經》成書在前，《持驗記》此條當係節引《壇經》（或其祖本）。

## 分類依據

- 往生欄位：全條無往生語，not-stated／unspecified／uncertain。
