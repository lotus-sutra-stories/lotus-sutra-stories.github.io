# 考證與異文 — 跋澄

## 版本與出處

- 見證一：《法華經顯應錄》卷一「高僧」門。**注意：原書條目題作「沙門澄法師」，題中不含人名首字，正文中人名作「䟷澄」。**末有夾注「靈瑞集」，為宗曉標示資料來源。
- 見證二：《法華經持驗記》卷一晉朝門「晉長安釋䟷澄」條，無來源夾注。
- 底本：CBETA X78, No. 1540／1541 數位版；兩本皆於 2026-10-23 核對。

## 文字校勘（兩本異文對照）

| 《顯應錄》（詳） | 《持驗記》（略） |
|---|---|
| 「立志誓誦蓮經，以求西邁」 | 「誓誦法華」 |
| 「生來愚鈍，隨分誦持」 | 「生來誦持」（無「愚鈍」句） |
| 「忉利雖是勝處，非所願也」 | 「忉利雖勝，非所願爾」 |
| 「此是西方寶城，階道來迎」 | 「是西方寶城來迎」 |
| 「言已向西，奄然而化」 | 「言已，向西寂然而化」 |

- 「䟷」＝CBETA gaiji CB02494，構件式描述〔跳-兆+(乏-之+友)〕，通用字作「跋」。題目與正文用字不一，依底本如實保留並於譯註說明。
- 《持驗記》謂「又一夕」，《顯應錄》作「又一時」。

## 分類依據

- aspirationForSukhavati=true：原文「專祈極樂」「以求西邁」明確可考。
- reportedDestination=sukhavati：夢中所見為「西方寶城」。
- rebirthClaim=interpreted：原文以夢境、異香、面西而化收束，未以敘事口吻明言往生，故不標「明言往生」。

## 待辦

- 譯註為編輯初稿，待獨立審校。
- 跋澄是否即前秦譯經僧「跋澄」（《阿含經》譯者之一）待考；兩本感應錄均未繫年，不宜遽斷。
